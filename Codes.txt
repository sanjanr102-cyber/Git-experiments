Experiment 1: Setting Up and Basic Commands
* Objective: Initialize a new Git repository in a directory, create a new file, add it to the staging area, and commit the changes with an appropriate commit message.
* Procedure:
# Step 1: Create a new directory and navigate into it
mkdir E1
cd E1

# Step 2: Initialize the Git repository
git init

# Step 3: Create a new file and check status
touch sample1.txt
git status

# Step 4: Add file to staging area
git add sample1.txt
git status

# Step 5: Commit the change
git commit -m "first time"

# Step 6: View the commit history
git log --oneline

Experiment 2: Creating and Managing Branches
* Objective: Write the commands to create a new branch, switch to it, make changes, and merge it.
* Procedure:
# Step 1: Check current branches
git branch

# Step 2: Create a new branch
git branch feature-branch

# Step 3: Switch to the new branch
git checkout feature-branch

# Step 4: Create a new file with content
echo "New Feature" > feature.txt

# Step 5: Check status and stage the file
git status
git add feature.txt

# Step 6: Commit changes on the feature branch
git commit -m "add new feature"

# Step 7: Switch back to master branch
git checkout master

# Step 8: Merge feature branch into master
git merge feature-branch

# Step 9: Verify branches and commit graph
git branch
git log --oneline --graph --all

Experiment 3: Stashing Changes
* Objective: Write the commands to stash your changes, switch branches, and then apply the stashed changes.
* Procedure:
# Step 1: Check current repository status
git status

# Step 2: Stash the uncommitted changes
git stash

# Step 3: Switch to another branch
git checkout feature-branch

# Step 4: View available stashes
git stash list

# Step 5: Apply the stashed changes back
git stash apply
